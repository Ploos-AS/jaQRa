# Contributing to jaQRa

Thanks for your interest. The project is in its initial setup phase.

- Open an issue with a clear problem statement and expected behavior before large changes.
- Submit small pull requests with tests for payload formatting, escaping, accessibility, or QR encoding.
- Never include real Wi-Fi passwords, TOTP seeds, personal contact records, or tokens in tests.
- Keep static QR generation fully local and usable without an account.
- Do not introduce dependencies that conflict with the planned MIT-licensed QR core without discussion.

The project license has not yet been finalized. Contributions will be reviewed with licensing compatibility in mind.
